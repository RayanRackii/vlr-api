# Agent feedback

Canonical history of **agent-system** mistakes and reusable learnings for Rolvix (`vlr-api` and `vlr-web`).

This is **not** a rule. A recorded incident does not bind future agents until it is **promoted** to CONTEXT, ADR, `.cursor/rules/`, a skill, agent routing, `AGENTS.md`, or a context pack.

Do not start tasks by reading `incidents/**`. Use [INDEX.md](./INDEX.md).

Do not store secrets, PII, or huge code dumps.

Frontend does not duplicate this folder; it points here from `vlr-web/AGENTS.md`.
